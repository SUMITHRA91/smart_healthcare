# 🩺 Smart Healthcare

A machine learning-powered healthcare analytics application built with **React** and **Python** that predicts patient health risks from ECG data and visualizes results through an interactive dashboard. The project combines modern frontend technologies with machine learning to provide healthcare insights in an intuitive interface.

## 🚀 Features

- 📊 Responsive React dashboard for healthcare monitoring
- ❤️ ECG signal preprocessing and feature extraction
- 🤖 Machine learning-based healthcare risk prediction
- 📈 Interactive charts for prediction visualization
- 📋 Patient analytics dashboard
- ⚡ Real-time prediction result display
- 📱 Responsive and user-friendly interface

## 📂 Project Overview

The Smart Healthcare system processes ECG signals, performs preprocessing and feature extraction, and uses machine learning classification algorithms to predict potential healthcare risks. The predictions are displayed on an interactive React dashboard with charts for easy interpretation.

---

## 🔍 Workflow

1. Load ECG data
2. Preprocess ECG signals
3. Extract relevant features
4. Predict healthcare risk using trained ML models
5. Display prediction results
6. Visualize analytics through interactive charts

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/SUMITHRA91/smart_healthcare.git
```

### Navigate to the project

```bash
cd smart_healthcare
```

### Install frontend dependencies

```bash
npm install
```

### Start the React application

```bash
npm start
```

### Install Python dependencies

```bash
pip install -r requirements.txt
```
